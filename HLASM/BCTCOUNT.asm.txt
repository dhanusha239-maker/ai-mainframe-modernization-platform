* ====================================================================
* LOOP EXAMPLE: ACCUMULATING SUM USING BRANCH ON COUNT (BCT)
* ====================================================================
BCTCOUNT  CSECT
          BASR  R12,0              Establish base register
          USING *,R12              Establish addressability
*
          XR    R3,R3              R3 = 0 (This will accumulate the sum)
          L     R4,COUNT           R4 = 10 (Loop counter)
*
LOOPSTART EQU    *
          AR    R3,R4             
          BCT   R4,LOOPSTART       
*
          ST    R3,TOTAL           
          XR    R15,R15            Set RC = 0
          BR    R14                Exit
*
* --------- DATA DEFINITIONS ---------
COUNT     DC    F'10'              Initial loop count
TOTAL     DS    F                  Storage for accumulated result
*
R3        EQU   3
R4        EQU   4
R12       EQU   12
R14       EQU   14
R15       EQU   15
          END
